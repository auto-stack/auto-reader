# Readest 实际 UI 研究（READER-006 T-03 / ui-study）

状态：tested · 2026-11-01。对象 = **Readest 0.12.16 Windows x64 官方 portable**（基线见 [baseline.md](baseline.md) §4：SHA256 `683a620d…`，tag v0.12.16 与源码分析基线同版）。原始运行记录与截图索引在仓外 `D:/autostack/plan-artifacts/plan-006/ui/`（runlog-u01.md + screens/*.png，共 30+ 张）；本文件是可独立理解的耐久摘要。

## 0. 方法与语料（如实声明）

- **驱动**：Computer Use 在本宿主不可用；改用 WebView2 CDP（`--remote-debugging-port=9223`）+ Playwright 1.62.1（与本仓自用验收驱动同族工具）。交互 = CDP 真实鼠标/键盘事件；观察 = ARIA 树 + 截图 + 只读 DOM 读取；选区 = 真实按下-拖动-抬起。原生文件对话框 = Win32 前置 + **剪贴板粘贴** + 回车（不用逐字符键入）。
- **隔离**：portable 模式（exe 旁 `Settings.json`）+ 独立 `WEBVIEW2_USER_DATA_FOLDER`；用户既有数据（%APPDATA% 3.8GB）全程零写入（快照核对）。首次运行曾以共享 WebView2 profile 启动，继承了用户云端会话并下载一本用户书目到隔离目录——已整目录重建，事件记入 C07 发现（见 §6）。
- **语料**：自制 `hello.epub`（中文混排+图+3 脚注+重复句×3+1200 段长章，218 页）、`hello.pdf`（Project Gutenberg Alice 文本型 69 页）、`hello.cbz`（7 页扫描漫画）、`hello.azw3`（中文神经科学样本）、`hello.fb2`、`hello.txt`。MOBI 无可生成语料（未测，代码证据见 code-map）。
- **诚实边界**：快速横向拖拽会被识别为翻页手势（选区需慢速拖）；PDF 文本层选区在 shadow-DOM 内，`window.getSelection()` 读不到但视觉渲染成立；OS 级读屏与盲文不在本轮范围。

## 2. U02 阅读与排版（EPUB 实测）

- **目录跳章 ✓**：侧栏 treeitem 点击即跳；显示各章页数与「当前位置」高亮。
- **脚注弹层 ✓**：点击 noteref 上标 → 浮层显示脚注原文（u02-footnote-popover.png）。
- **图片查看器 ✓**：单击正文图 → 全屏查看器（缩放 +/−、全屏、分享、题注、上一张/下一张图库导航）。
- **排版设置 ✓**：默认/最小字号（16→20 即时重排）、字重、衬线/无衬线/等宽类别（Bitter/Roboto/Consolas）、**中文字体=霞鹜文楷**、管理自定义字体、覆盖书籍字体开关。
- **滚动/分页双模式 ✓**：滚动模式（Shift+J）跨章连续；分页模式双栏对页（宽窗）/单栏（开侧栏）自适应；另有自动滚动、段落模式（Shift+P）、快读模式（Shift+V）。
- **主题 ✓**：浅/深/自动 + 色彩预设（默认/素雅/旧韵）+「深色下图片反色」开关；主题作用域分**书库/阅读界面**两轨（实测改阅读界面主题书库不变）。
- 渲染结构（只读观察）：`<foliate-view>`(shadow)→`<foliate-paginator>`(shadow)→每 spine 一 iframe；相邻章预停靠屏外；**长章 iframe 宽 133,280px**（1200 段分栏布局）。
- 缺陷观察（轻）：页码状态「第 X 页」与进度 `[1,218]` 滞后于实际位置（CFI location 前进而页计数不动，书卡 0%），0.12.16 计数口径待查。

## 8. 结论要点（供 report/decisions 引用）

1. **核心日用任务（导入→阅读→选区标注→搜索→重启恢复→导出）全链实测通过**，其中定位/标注以 **EPUB CFI 字符偏移** 为锚（AutoReader 为章+段+逐字全文锚——迁移设计的关键对照）。
2. **两个 Windows 0.12.16 实证缺陷**：对话框导入受管副本缺失且打开静默失败；软删记录不去重。另有一处删除确认待复验。
3. 产品广度显著：重复句批量标注、导出深链、阅读统计/段落模式/快读、漫画/有声/OPDS/多同步后端（多数服务面需账号，缺证具名）。
4. 工程形态：WebView2 + React/Next + foliate-js fork（iframe 分节 + 分栏 paginator），长章以超宽 iframe 分栏预渲染——对 AutoUI 原生 VM 表面是不可直接移植的 DOM 重度依赖。
